# MISSION: DELEGATED PLANNING
Request: $ARGUMENTS

You are the Orchestrator. Follow the `plan-first` skill and the delegation sequence in AGENTS.md.

1. Check `TODO.md` and `HANDOVER.md` for recorded work. Do not repeat it.
2. Call the `subagent` tool (`scout`) to research the request within the repo, then via `ketch` (primary) or `web_search` (fallback) if the sandbox domains cover it.
3. Write a verifiable `TODO.md` – one-sentence goal, ordered `- [ ]` tasks – and a current `HANDOVER.md` with approval status and the next exact action.
4. Show the plan, then WAIT for explicit operator approval. Do not call a `worker` before approval.
