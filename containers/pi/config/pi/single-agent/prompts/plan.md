# MISSION: PLAN
Request: $ARGUMENTS

Follow the `plan-first` skill and the workflow in AGENTS.md.

1. Read `AGENTS.md` (if present), the repo structure, and existing `TODO.md` and `HANDOVER.md`. Do not repeat recorded work.
2. For a new request, ask only blocking questions and WAIT for answers.
3. Write a verifiable `TODO.md` – one-sentence goal, ordered `- [ ]` tasks, constraints – and a current `HANDOVER.md` with decisions, approval status, and the exact next action.
4. Show the plan and WAIT for explicit approval ("Reply YES to start, or tell me what to change"). Do not implement before approval.
On resumption, update the existing checkpoints rather than starting over.
